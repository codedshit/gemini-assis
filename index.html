3. Create the bookmark (iPad Safari / Chrome)

  1. In Safari, bookmark any page (Share → Add Bookmark) and Save.
  2. Open Bookmarks → Edit, tap the new bookmark.
  3. Rename it to Gemini Assistant.
  4. Replace the URL by pasting the production bookmarklet you copied above.
  5. Done — open any webpage and tap the bookmark to launch the assistant.
Tapping the bookmark again while the assistant is open just re-focuses it. It never creates duplicate windows.

4. Add your Gemini API key (in the assistant)

Open the assistant, tap ⚙ Settings → AI, paste your Gemini API key, tap Save, then Test Connection. Pick your model (default gemini-3.6-flash).

Never commit your API key to GitHub. The key is stored only in your browser. For production, host a small serverless proxy and set PROXY_URL so the key stays server-side.
